# Инопоиск Флюс — «Отписаться»

Одна цель — отменить подписку вымышленного сервиса «Инопоиск Флюс». Между вами и кнопкой —
тёмные паттерны: «вы уверены?», скидка, опрос из 6 вопросов, чат-бот, капча, таймер
ожидания оператора, головоломки.

Согласились оставить подписку (нажали «остаться», приняли скидку, не сняли галочку) —
игра начинается заново с первого уровня. **Таймер и счётчик кликов при этом не
обнуляются.** В финале — поздравление, «подарок от партнёров» и колесо фортуны.

> ⚠️ Пародия. «Инопоиск Флюс» — вымышленный сервис, совпадения с реальными компаниями
> случайны. Логотипы, шрифты и цвета реальных брендов не используются.

## Стек

Vite + TypeScript, без фреймворка. Деплой — GitHub Pages
(`github.com/Estogeronium/Unsubscribe`). Целевой адрес — `unsubscribe.vonzvyagin.ru`
(поддомен, `public/CNAME`), пока также доступно на `estogeronium.github.io/Unsubscribe/`.

На финале кнопка «Поделиться результатом» шлёт `text` + `url` (адрес игры) через Web Share API.

**Превью ссылки (og:image).** Мета-теги Open Graph / Twitter — в `index.html`, абсолютные,
указывают на `https://unsubscribe.vonzvyagin.ru/`. Картинка `public/og.png` (1200×630),
исходник `design/og-card.svg` (контент в центральной полосе 1200×630 внутри квадрата
1200×1200 — так его крутит `qlmanage`). Фавикон — `public/favicon.svg`.

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # тайпчек + прод-сборка в dist/
npm run preview  # предпросмотр сборки
```

Без хэша игра открывается с интро-экрана; таймер и клики стартуют по кнопке «Начать отмену».
Открыть `#7` в адресной строке — пропустить интро и начать сразу с 7-го уровня (для отладки).

`preview/index.html` — отдельная play-версия одним файлом на чистом JS (без сборки).
Открывается двойным кликом, используется для быстрого плейтеста и как артефакт.
**Держим её вручную синхронной с `src/`.** Переключатель уровней виден только по `?dev`
в адресе; в консоли всегда доступны `__ipp.goto(n)`, `__ipp.twist(i)`, `__ipp.intro()`.

## Деплой

CI — `.github/workflows/deploy.yml`: push в `main` → GitHub Actions → `npm run build`
(`tsc --noEmit && vite build`) → публикация `dist/` на GitHub Pages. Локально Node не нужен.
`configure-pages` с `enablement: true` — Pages включается сам, руками в Settings не надо.

Обновление: коммит через **GitHub Desktop** (Summary → Commit to main → Push origin),
Action пересобирает автоматически, ~1–2 мин.

**Свой домен `unsubscribe.vonzvyagin.ru`.** GitHub Pages отдаёт сайт с корня
домена/поддомена (произвольный путь не поддерживается), поэтому взят поддомен.

1. У DNS-провайдера домена `vonzvyagin.ru` добавить запись:
   `CNAME`  `unsubscribe`  →  `estogeronium.github.io`
2. `public/CNAME` (уже в репозитории) содержит `unsubscribe.vonzvyagin.ru` — GitHub
   подхватит домен из него при деплое.
3. GitHub → репозиторий → Settings → Pages → Custom domain: `unsubscribe.vonzvyagin.ru`
   → дождаться «DNS check successful» → включить **Enforce HTTPS** (сертификат ~до часа).
4. og-теги и кнопка «Поделиться» уже указывают на этот адрес (`index.html`,
   `src/levels/level-99-fortune.ts`, `preview/index.html`).
5. Прогреть превью в Телеграме: отправить ссылку боту `@WebpageBot`.

Если первый Action упал красным — это почти всегда ошибка `tsc`; лог во вкладке Actions.

## Как добавить уровень

1. Создать `src/levels/level-NN-name.ts`, экспортировать объект `Level`.
2. `mount(root, game)` рендерит DOM в `root`. Вызвать `game.complete()` — перейти дальше;
   `game.fail(текст)` — показать экран провала и рестарт (таймер/клики сохраняются);
   `game.penalize(мс)` — штраф ко времени.
   Вернуть функцию очистки, если ставите таймеры/слушатели.
3. Добавить в массив `levels` в `src/levels/index.ts` перед `ending`.
4. Продублировать логику в `preview/index.html`.

Готча: глобального `[hidden]{display:none}` в проекте нет. Если прячете элемент через
`el.hidden`, не задавайте ему `display:` в базовом правиле — используйте
`.foo{display:none} .foo:not([hidden]){display:flex}`.

## Осталось по плану

20 уровней + финал + «повороты» + звук готовы. Дальше — финализация и деплой.

**Звук** (`src/engine/sound.ts`) — всё синтезируется осцилляторами, ассетов нет.
Глобальный тик на клики по кнопкам/ссылкам; `blip` на переход уровня и сообщение Стеши;
`fail` на провал; `win` + `wheelSpin` на финале; `tick` на последних секундах у оператора.
Тумблер 🔊/🔇 в HUD, выбор в `localStorage["ipp-sound"]`, **по умолчанию ВКЛ** (тихо,
master 0.14). Поменять дефолт — `readEnabled()` в `sound.ts`.

**«Повороты»** (`src/engine/twists.ts`) — короткие экраны между уровнями по `before`-индексу:
перед L5 «приложение обновилось», перед L10 «сессия завершена, войдите снова» (+штраф),
перед L13 «включили тёмную тему», перед L16 тема возвращается. Показываются один раз;
при провале `data-theme` сбрасывается.

В `preview/index.html` есть временный переключатель уровней (`<details class="lvlnav">`,
помечен «в релизе убрать») — вырезать при финализации. Дев-хелперы: `__ipp.goto(n)`,
`__ipp.twist(beforeIndex)`.
